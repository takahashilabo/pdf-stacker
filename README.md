# PDF Stacker

複数回の印刷結果をPDFとして蓄積し、不要なページを削除してから1つのPDFにまとめてダウンロードできるChrome拡張機能です。

## しくみ

ツールバーのアイコン(またはショートカットキー)をクリックすると、Chromeのネイティブ印刷と同じ仕組み(`chrome.debugger` の `Page.printToPDF`)で現在のページをその場でPDF化し、ファイルには保存せず1ページずつブラウザ内(IndexedDB)のスタックの末尾に追加します。管理画面で全ページのサムネイルを確認しながら不要なページを削除し、最後に残ったページをまとめて1つのPDFとしてダウンロードできます。

## インストール方法(デベロッパーモード)

Chrome Web Storeには公開していないため、以下の手順で手動インストールしてください。

1. このリポジトリをダウンロードまたはクローンする
   ```
   git clone https://github.com/takahashilabo/pdf-stacker.git
   ```
2. Chromeで `chrome://extensions` を開く
3. 右上の「デベロッパーモード」をONにする
4. 「パッケージ化されていない拡張機能を読み込む」をクリックし、クローンした `pdf-stacker` フォルダを選択する

以降、拡張機能アイコンがツールバーに表示されます。

### アップデート方法

```
git pull
```
した後、`chrome://extensions` で拡張機能の「再読み込み」ボタンを押してください。

## 使い方

1. PDFに含めたいページを開き、拡張機能アイコンをクリック→「＋ このページを追加」
   - またはショートカットキー `Ctrl+Shift+S`(Macは `Command+Shift+S`)で、ポップアップを開かずに直接追加できます
   - キャプチャ中、Chromeの仕様で「"PDF Stacker" がこのブラウザをデバッグしています」という通知バーが一瞬表示されますが、1秒程度で自動的に消えます
2. 上記を繰り返して、ページをスタックに蓄積していく
3. アイコン→「スタックを管理...」を開くと、蓄積した全ページのサムネイル一覧が表示される
   - 不要なページは「このページを削除」で個別に削除できる
   - 「すべて削除」でスタックを空にできる
4. 「1つのPDFとしてダウンロード」を押すと、残っているページを結合した1つのPDFファイルがダウンロードされる

## 権限について

- `debugger`: `Page.printToPDF` を呼ぶために必要です(ネイティブ印刷と同じ描画結果を、ダイアログを開かずに取得するため)
- `activeTab`: キャプチャ対象の現在のタブ情報を取得するために必要です

## 使用ライブラリ

- [pdf-lib](https://pdf-lib.js.org/)(ページの分割・結合)
- [pdf.js](https://mozilla.github.io/pdf.js/)(サムネイル描画)
